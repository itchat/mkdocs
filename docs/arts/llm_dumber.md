# 从长远来看，大语言模型让我们变得更愚蠢[^1]

当我们把认知负担卸载到大型语言模型中时，我们得到的舒适感其实对我们并不利。认知负担应该是存在的，如果我们过度减轻这种负担——即停止思考——那么我们实际上就会失去思考的能力。

那些总是选择简单路线、抄袭其他学生作业的孩子，最终会完全不清楚学校里发生了什么。那些总是让配偶处理所有账单和银行事务的人，也许有一天连简单的付款都无法自己处理。而那些从不努力学习街道名称或路线的人，一旦手机无法使用，他们甚至不知道如何回家。

这一切都源于纳西姆·塔勒布在其有深刻见解的著作《反脆弱》中所提出的观点——即少量的压力或不适会让我们变得更强大。

- 肌肉通过举重来增长。

- 免疫力是通过接触而获得的。

- 通过承担风险可以增强信心。

- 通过反复练习，技能可以得到提升。

- 通过解决难题，创造力得以拓展。

- 思维也是以同样的方式运作的。思考过程中的摩擦、寻找恰当词汇的艰难挣扎——这些都是心理上的“举重运动”。

也许可以举一个稍微不同的例子，但道理是一样的——那就是“破窗理论”。该理论认为，那些明显的混乱迹象——比如涂鸦、垃圾或破损的窗户——表明人们容忍了这种无序状态，这会降低对非正式行为的监管，从而让更多的不良行为甚至严重犯罪行为得以发生。换句话说，当这些小问题被忽视时，它们可能会逐渐演变成更大的问题。而不断依赖大型语言模型，会让这种情况越来越严重，最终我们所有的思考都将被外包出去，变成纯粹的生物机械装置而已。

甚至还有最新的研究来支持这一观点。在一项研究中，参与者被分为三组：

- 仅使用大脑进行写作：在没有辅助的情况下完成了文章创作。

- 搜索引擎：使用谷歌搜索功能。

- LLM（ChatGPT）：完全依赖 ChatGPT 来完成工作。

而结果如下：

- 在 LLM 小组中，有 83%的人在写作后无法从自己的文章中引用任何内容，而其他小组中的几乎所有人都能够做到这一点。

- 从语言模型转向独立写作的参与者，其神经活动减弱，且持续处于低参与状态。

- 那些从仅使用大脑系统进行思考转变为使用大语言模型的参与者，仍然保持了出色的记忆能力，其神经激活模式与搜索引擎小组的成员相似。

在每个小组中，有百分之几的参与者在引用论文中的内容时遇到了困难？

他们创造了“认知债务”这一术语，用来描述这种权衡：虽然人工智能的辅助可以带来即时的便利，但代价是长期的认知能力会受到影响，比如批判性思维、记忆保持能力以及创造性思维的能力。人们从机器那里借用了思维资源，但这笔“利息”最终会体现在自己的思维能力减弱上。

我一直在跟我的孩子们强调这一点——机器学习确实是一种非常强大的工具，但必须谨慎使用它。不要让它来解答你的数学问题；而是让它本身给出解决方案，并让它能够指出你的错误所在。从培养独立思考能力开始，然后再结合人工智能的应用，这样更有利于认知发展。这就好比核能——你可以将其用于大规模破坏，也可以作为清洁的能源来源。

过度依赖人工智能工具可能会削弱学习、记忆和创造力。不适感不仅仅是一种麻烦，它其实是一种锻炼的机会。

寻找不适感，主动去接触它，并鼓励这种不适感的存在。
